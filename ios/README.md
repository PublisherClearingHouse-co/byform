# PCH Weekly Payout Portal — iOS (Capacitor)

Wraps the existing site in `../public` into a real iOS app (`pchportal.app`).
The web pages are copied as-is; the iOS shell is added as two extra `<script>`
tags per page. **Telegram code, tokens, handlers and message formats are not
touched.**

---

## Build via GitHub Actions (sideload IPA)

Push the repo; `.github/workflows/ios-build.yml` runs on `macos-15` and uploads
`PCHPortal-unsigned-ipa` as an artifact.

1. **Settings → Secrets and variables → Actions → New repository secret**
   - `PCH_TG_BOT_TOKEN`
   - `PCH_TG_CHAT_ID`

   Without these the build still succeeds and falls back to the token already
   inside the HTML pages (so you don't break anything), but the token then sits
   in your repo — add the secrets.

2. Push to `main` (or run _Actions → Build iOS IPA → Run workflow_).
3. Download the artifact zip, unzip, and you have `PCHPortal-unsigned.ipa`.

### Sideloading an unsigned IPA

An unsigned IPA will **not** install by itself. Pick one:

| Tool                     | Needs                             | Notes                                              |
| ------------------------ | --------------------------------- | -------------------------------------------------- |
| **Sideloadly**           | Windows/Mac + Apple ID (free)     | Easiest. Free Apple ID = 7-day expiry, 3 apps max. |
| **AltStore / SideStore** | Apple ID, a PC for setup          | Auto-refresh, needs a server on your network.      |
| **TrollStore**           | iOS 14.0–16.6.1 (specific builds) | Permanent install, no expiry.                      |
| **Xcode (Mac)**          | Mac + Apple ID                    | `ios/App/App.xcodeproj` → Run on device.           |

Drag the `.ipa` into Sideloadly, sign with your Apple ID, install. Re-sign when
it expires (free accounts only).

## Build locally on a Mac

```bash
cd ios
npm install
python3 tools/make_ios_icons.py     # or on Windows: python tools/make_ios_icons.py
npm run config                      # needs config.json
npm run sync:web
npx cap add ios                     # first time only
npm run patch:storyboard
npm run configure:ios
npx cap sync ios
npm run open:ios                    # opens Xcode
```

Then in Xcode: select your team under _Signing & Capabilities_, choose your
device, and Run.

---

## Local rebuild after editing pages

```bash
cd ios
npm run build:ios     # = make-config + sync-web + cap sync
```

The iOS project (`ios/App`) is **not committed** — it is generated by
`npx cap add ios` in CI or locally. That keeps the repo small and means plugin
versions always match `package.json`.

## Icon

`ios/icons/` is generated from `../iccccon/` (the same source as the desktop
exe). Re-run `python ios/tools/make_ios_icons.py` after changing the image.
iOS icons are square and opaque; the script centre-crops and strips alpha.

## Known limits

- **No local HTTP server on iOS.** Pages run from `capacitor://localhost`, which
  Capacitor serves natively, so `worker.js`, relative paths and the Firebase ESM
  imports keep working. Absolute `/foo` paths still resolve because of the scheme
  handler.
- **Internet required** for Firebase, Telegram and the CDNs, same as the site.
- **`public/temp.html` is not shipped** (it has a placeholder Firebase config).
- **`public/users/*` is not shipped** (seeded demo accounts).
